PURDUE IT / PMO KNOWLEDGE SHARING04
Takeaways for project managers

What I would teach another PM

Use AI for speed, but keep people accountable for the accuracy of project status.

MAKE IT EASY TO FIND

Create a shared project page with clear context and documents.

KEEP ONE WORKING SOURCE

Use the spreadsheet for the underlying checklist and status data.

PROMPT AND VALIDATE

Request the latest refresh and review the reported figures.

Copilot speeds up reporting; the PM still owns the quality check.
